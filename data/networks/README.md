# Networks

* `Net3` is loaded from the WNTR library (EPANET example network).
* `ky6.inp` is the KY6 system from the University of Kentucky Water Distribution System Research
  Database (https://uknowledge.uky.edu/wdst/). Redistributed here for convenience only: please obtain it
  from the source and cite the database (check the database page for the preferred citation) when you use it.

Networks that were checked and are NOT used yet (findings from the health checks): Hanoi (design benchmark, under-pressured
as distributed), C-Town #33 (no demands in the file), KY13 (only solves in the EPANET engine), KY3 (WNTR and
EPANET disagree), KY8 (WNTR solver fails), Anytown (only a binary .NET file was available).
